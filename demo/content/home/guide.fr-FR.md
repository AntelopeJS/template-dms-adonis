## Comment utiliser ce tableau de bord

1. **Ouvrez Helio** dans le menu de gauche : le tableau de bord résume l'activité, chaque entrée mène à un domaine (ventes, opérations, factures, supervision, paramètres).
2. **Agissez vraiment** : créez un devis, faites avancer une affaire dans le pipeline, résolvez un ticket, marquez une facture payée. Les indicateurs suivent.
3. **Passez en téléphone** : réduisez la fenêtre, les tableaux deviennent des cartes.
4. **Ouvrez les Modules** (en bas à gauche) : chaque module a sa page d'accueil, et le store montre ceux qu'on peut ajouter.
5. **Changez de langue** dans votre profil : toute l'interface et les contenus Helio suivent.
