## Getting the most out of AI

AI is all the more effective when it has a framework. AntelopeJS gives it one.

- **Skills travel with the packages** — every installed module brings its documentation for agents (`dms`, `dms-best-practices`, `dms-project`, and the modules' own). The antelopejs plugin syncs them into Claude Code and Codex.
- **Describe the business, not the code** — "a Projects page with a table filterable by status, a detail view and one rule: the end after the start". The agent knows which blocks and APIs to use.
- **One task, one check** — ask for one thing, check it in the browser, move on.
- **The built-in assistant** — the Assistant module works right inside the dashboard, with the same skills.

### The real productivity gap

With AI alone, without this foundation, you would have had it invent authentication, permissions, multiple workspaces, complete tables, robust forms, real time, notifications, billing… and then make all of it consistent. That is weeks of work with a fragile result — and out of reach for a less technical profile.

With AntelopeJS, AI only writes the part that changes from one project to the next: the business. The rest is already there, tested and consistent. That gap is what takes a project like Helio from several months to one day.
