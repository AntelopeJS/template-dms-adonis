## What the DMS provides before your first line of code

When you start a project, these building blocks are already there, configured and consistent with one another:

- **Accounts and security** — sign-in, invitations, two-factor authentication, sessions, password reset.
- **Roles and permissions** — every page, block and button is a permission the role editor knows how to show.
- **Multiple workspaces** — several clients on one platform, with isolated data.
- **Complete tables** — filters, search, sorting, saved views, bulk selection, export, archives, side panel, cards on phones.
- **Forms** — validation, dependent fields, addresses, relations, drafts, inline creation.
- **Dashboards** — KPIs, charts, periods and comparisons, real time.
- **Notifications, settings, languages, light and dark themes, global search, command palette.**

The project itself only declares what is its own: its data, its screens, its rules. That is why one day is enough.
