## Utiliser l'IA au mieux

L'IA est d'autant plus efficace qu'elle a un cadre. AntelopeJS lui en donne un.

- **Les compétences voyagent avec les paquets** — chaque module installé apporte sa documentation pour agents (`dms`, `dms-best-practices`, `dms-project`, et celles des modules). Le plugin antelopejs les synchronise dans Claude Code et Codex.
- **Décrivez le métier, pas le code** — « une page Chantiers avec un tableau filtrable par statut, une fiche détaillée et une règle : la fin après le début ». L'agent sait quels blocs et quelles API utiliser.
- **Une tâche, une vérification** — demandez une chose, vérifiez-la dans le navigateur, passez à la suivante.
- **L'assistant intégré** — le module Assistant travaille directement dans le tableau de bord, avec les mêmes compétences.

### Le vrai écart de productivité

Avec une IA seule, sans cette base, il aurait fallu lui faire inventer l'authentification, les permissions, le multi-espace, des tableaux complets, des formulaires robustes, le temps réel, les notifications, la facturation… puis rendre tout cela cohérent. C'est des semaines de travail, avec un résultat fragile — et hors de portée d'un profil moins technique.

Avec AntelopeJS, l'IA n'écrit que la partie qui change d'un projet à l'autre : le métier. Le reste est déjà là, testé et cohérent. C'est cet écart qui fait passer un projet comme Helio de plusieurs mois à une journée.
